# 训练计划交互原型

文件：[fitness-plan.html](../../output/fitness-plan.html)。可直接用浏览器打开，无外部脚本、字体或样式依赖。

依据：[原型需求](../需求/训练计划原型.md)及用户提供的参考图。2026-10-23 已按用户要求迁入 React 纯前端，新增历史统计与数据管理。正式页面通过 `pnpm dev` 启动；此 HTML 留作设计参考。NestJS 已移除。

## 视觉与页面

手机优先：浅米色背景、深色标题、橙色主要按钮。训练分化沿用参考图的蓝、绿、黄、橙色小标识。电脑端增加侧栏和双列分化卡片。

推荐页只展示「好人松松训练计划（四分化）」，以大号 04 和文字图形呈现，不预设其他计划。确认后进入四分化卡片，初始不展示动作。

设置在手机上为全屏页面，电脑上为弹窗。动作按原图的肌群和动作类别分组，推荐总量显示在分类标题旁。腿臀页保留参考图的轮换侧重点说明。

训练页顶部显示本次分化、已完成 / 目标组数和下次部位。当前分化单独置顶，结束按钮放在当前分化之后，其他三个分化按接下来的训练顺序排列。动作行使用短条显示组数，+1 记录，− 撤销。2026-10-23 调整后，无需做满目标组数即可结束训练并进入下一分化，实际组数保留，不补满目标。
