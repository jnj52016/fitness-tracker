# 健康检查

状态：2026-10-23 随 NestJS 移除而停用。以下为旧接口说明，仅供历史归档引用，当前应用不提供此端点。

接口定义：[health.openapi.yaml](health.openapi.yaml)。

`GET /api/health`，无请求参数，无需认证。正常时返回 HTTP 200：

```json
{ "status": "ok" }
```

此接口只确认 API 进程能够响应，不检查数据库或任何业务能力。前端开发服务将 `/api` 代理到后端，便于后续对接。

当前已有最小实现，实际验证结果见[基础框架归档](../归档/基础框架/2026-10-22.md)。
