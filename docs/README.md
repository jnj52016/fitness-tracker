## 维护规则

需求讲「做什么」，设计讲「如何呈现」，API 讲「如何对接」，TODO 讲「下一步做什么」。各目录 README 维护本类资料索引。

近期任务进入 TODO；暂时不做的进入可选功能并记录原因；验收完成后进入归档，TODO 仅保留简短链接。确定取消的事项记录取消原因后归档，不标为完成。

正式需求、设计与接口资料持续维护在原目录，归档通过链接引用，避免重复版本。文档、原型、前端、后端、真实联调分别记录进度；一个阶段完成不代表整个功能完成。

任务只有 `TODO` 和 `DONE` 两种状态。未完成用 `- [ ] TODO`，开始处理后仍保持不变；验收通过才用 `- [x] DONE`。未执行、失败或被阻塞的检查如实记录。

当前代码为 React 前端 + Node.js / SQLite 后端，使用用户名密码登录，按账号保存训练配置、进度与历史，用户端仅保留训练与历史页面。当前范围见[账号与后端存储](需求/账号与后端存储.md)，进度见 [TODO](todo.md)。用户给出的其他项目 TODO 仅作为写法参考，不是本项目功能范围。
