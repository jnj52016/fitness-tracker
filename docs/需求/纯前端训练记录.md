## 当前架构

React + TypeScript + Ant Design + Vite，pnpm 管理。移除 NestJS 应用、后端依赖和开发代理；不提供登录、服务器数据库或跨设备自动同步。

正式数据统一存储在 IndexedDB。保留原型的布局与四分化动作目录，不默认展示或选中动作。

## 训练规则

唯一展示计划为「好人松松训练计划（四分化）」。背 + 肩后束 → 胸 + 肩前中束 → 腿臀 → 大臂 + 腹，按顺序循环，休息日自由安排。

当前分化置顶，其他分化按后续顺序排列。各分化设置中勾选动作、调整 1–20 组；新勾选动作默认 4 组，推荐总量按参考图的肌群或动作类别显示。

当前分化可以加组、撤销，完成组数不超过目标也不低于零。修改配置如果会删减当前组数，须确认；已经结束的历史快照不随设置修改。

无需做满组数即可结束。结束时保存动作、目标、实际完成组数及开始 / 结束时间，然后进入下一分化。零组结束也留记录，标为「未训练」，不计入累计训练次数。再次轮到同一分化时，本轮计数归零，历史保留。

跨天不自动结束或重置本轮。历史日期按训练结束时设备的本地日期记录。

## 历史与统计

历史支持查看当次动作明细、按分化和月份筛选、分批加载。统计累计有效训练次数、实际完成组数、去重训练天数，以及各分化组数。统计仅包括已经结束的训练；正在进行的本轮在训练页展示。

## 本地数据与备份

操作在 IndexedDB 写入成功后更新页面，失败明确提示，不用内存成功冒充持久化。刷新、关闭后重开可恢复；多标签页使用版本检查，拒绝旧状态覆盖新状态。

导出 JSON 包含配置、本轮进度和全部历史。导入先校验版本、动作、组数、时间和重复记录，并显示内容摘要；用户确认后才替换当前数据。坏文件或写入失败不得覆盖原记录。清空数据另行确认。

记录只属于当前浏览器与网址，不自动跨设备同步；清理网站数据可能丢失，用户通过导出备份自行保管。旧 HTML 原型数据与正式应用分开，保留原型文件及数据，不伪造历史迁移。

当前不实现离线站点缓存、账号或云同步。

## 验收

基础流程：首次选择 → 配置 → +1 / 撤销 → 刷新恢复 → 提前结束 → 下一分化 → 历史详情 / 统计 → 导出 → 清空 → 导入恢复。

错误流程：非法备份不覆盖数据；保存失败不推进界面；不同标签页的旧版本写入被拒绝。实际结果见[本轮归档](../归档/纯前端训练记录/2026-10-23.md)。
