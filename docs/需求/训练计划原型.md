# 训练计划 HTML 原型

需求来源：用户于 2026-10-22 的说明与四分化训练参考图。

## 本轮范围

先制作独立 HTML，供用户评审设计和交互；以手机端为主，同时适配电脑。不接入正式前后端。

进入页面先展示训练计划推荐，目前只展示「好人松松训练计划（四分化）」。选择确认后展示四个分化模块：背 + 肩后束、胸 + 肩前中束、腿臀、大臂 + 腹。

初始模块只显示分化名称，不默认展示具体动作。点击模块的设置才展示参考图中的推荐动作与组数。用户可选择动作，调整各动作组数，保存后返回主页面。

主页面展示已选择的动作、目标组数和完成组数。点击动作后的 +1 表示完成一组，让用户清楚已练什么、还要练什么和下一次训练的部位。

## 原型中的待确认交互

原型按背、胸、腿臀、大臂和腹依次循环。2026-10-23 用户确认调整：当前训练分化置于其他分化上方；即使未做完全部组数，也可以点击「结束本次训练」进入下一分化。保留实际完成组数，不自动补满目标；结束状态不代表目标全部完成。未轮到的分化可以配置，但不记录组数。该顺序不是固定连续四天训练。

每个新选动作初始填入 4 组，可调整到 1–20 组。这是演示交互的默认值，不是把参考图推荐总量当成单动作建议。推荐量按肌群或动作类别单独展示。

支持撤销误加的一组。设置和本轮进度保存在浏览器本地；同一分化再次轮到时清空其完成数，保留动作设置。不包含账号同步、按日期历史或统计。

以上细节待用户查看原型后确认，不视为正式业务规则已定稿。
