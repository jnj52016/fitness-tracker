# 基础框架

确认日期：2026-10-22。

2026-10-23 更新：用户已明确改用纯前端，NestJS 后端已移除。本文保留最初框架范围的历史记录，当前实现以[纯前端训练记录](纯前端训练记录.md)为准。

## 已确认范围

- 前端使用 React、TypeScript、Ant Design。
- 后端使用 Node.js、NestJS。
- 使用 pnpm 管理依赖与前后端工作区。
- 建立用户指定的 docs 分类、导航、TODO 和归档流程。
- 保留应用入口、开发与构建脚本、环境配置，以及基础健康检查。

## 范围边界

具体业务需求尚未提供。当前不实现打卡表单、记录管理、统计、登录、数据库或其他业务功能，也不预先确定数据模型与产品界面。先前自行添加的打卡实现应删除，不作为已确认需求或待恢复功能。

## 框架验收要求

使用 pnpm 安装依赖、通过类型检查与构建；前端提供最小占位页面，后端健康检查可访问；docs 分类入口可导航，TODO 与实际完成情况一致。业务需求、原型和业务联调另行确认与验收。

验收记录见[基础框架归档](../归档/基础框架/2026-10-22.md)。
