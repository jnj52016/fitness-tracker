# 2026-10-23：当前训练置顶与提前结束

用户反馈：当前训练放到最上面，即使没有完成全部组数也能结束。

- [x] DONE 当前分化独立置顶，结束按钮紧随其后，其他分化按后续顺序排列。
- [x] DONE 结束按钮不再受目标组数限制；结束后保留实际组数，进入下一分化。卡片状态使用「本轮已结束」，避免把结束当作完成全部目标。
