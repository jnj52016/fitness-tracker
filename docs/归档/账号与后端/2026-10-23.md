## 实际验证

- 工作区 `pnpm -r typecheck` 通过，包含前端类型检查、共享模型检查及后端语法检查。
- 工作区 `pnpm -r build` 通过。Vite 提示主 JS 超过 500 kB，构建正常，未在本轮拆包。
- 工作区 `pnpm -r test` 通过：前端 22 项 + 后端 2 项，共 24 项。
- 后端使用真实 HTTP 和临时 SQLite 验证注册重名、错误密码、会话 Cookie、账号隔离、账号切换拒绝访问、并发冲突、非法数据拒绝、注销与到期、服务重启持久化、密码非明文、Origin 校验和认证限流。
- 前端模拟 DOM 验证注册登录退出、训练设置加组与历史、导入清空、旧数据迁移先确认和取消、保存失败不推进；HTTP 客户端验证账号标识、revision、401 会话通知及断网不本地回退。页面回归用兼容 IndexedDB 模拟存储，不能声称为真实浏览器前后端端到端验证。
- `pnpm dev` 实际启动两个工作区；开发入口 http://localhost:5173/，开发代理健康检查返回 200；Node 的构建页面与 JS 资源返回 200。
